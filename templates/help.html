AutoCert v1.1 主要功能与操作说明

01

证书管理

集中保存服务器证书及私钥，自动读取颁发机构、适用域名和到期时间，并对一个月内到期或已经过期的证书进行提醒。

  1. 进入“证书”，点击“上传证书”。
  2. 填写名称，选择证书文件和匹配的私钥文件。
  3. 上传后检查自动识别的信息，并按需要补充备注。
  4. 点击关联站点数量，可查看正在使用该证书的站点。
02

站点与部署脚本

维护目标服务器 SSH 信息、关联证书和 Shell 脚本。部署时，系统先通过 SFTP 上传证书，再在目标服务器执行脚本。

  1. 进入“站点”，新增目标服务器并选择密码或私钥认证。
  2. 选择需要部署的证书。
  3. 在脚本中使用 {{ '{{CERT_PEM}}' }} 和 {{ '{{CERT_KEY}}' }} 引用远端临时文件。
  4. 保存后可点击“立即部署”，系统会记录成功或失败结果。
install -m 0644 {{ '{{CERT_PEM}}' }} /etc/nginx/cert/default.pem
install -m 0600 {{ '{{CERT_KEY}}' }} /etc/nginx/cert/default.key
nginx -t
nginx -s reload
03

定时任务

使用标准五段 cron 表达式，在上海时区按计划执行站点当前关联的部署脚本。

  1. 进入“定时任务”，选择站点并填写 cron 表达式。
  2. 输入框下方会显示下一次具体执行时间。
  3. 保存并启用任务；列表会显示上次和下次运行时刻。
  4. 例如 0 2 * * * 表示每天凌晨 2 点执行。

程序必须持续运行，停机期间的定时任务不会执行。

04

用户与权限

管理员拥有全部权限，可维护用户、证书、站点和任务；普通用户只能查看业务数据。

  1. 管理员进入“用户”可新增或编辑账号并选择角色。
  2. 普通用户看不到写操作按钮，直接访问写操作地址也会被拒绝。
  3. 所有用户都可点击右上角用户名修改自己的密码。
  4. 首次登录后应立即修改默认密码。
05

使用与安全提示

  • 建议只在管理网或 VPN 内开放本系统，并通过 HTTPS 访问。
  • 目标服务器应使用独立、低权限的 SSH 账号，仅授予证书目录和服务重载所需权限。
  • 脚本以 SSH 用户权限运行，不要使用需要交互输入的命令。
  • 请完整备份 data 目录；其中包含数据库、证书、会话密钥和 SSH 凭据加密密钥。
  • 部署前先在测试站点验证目录权限、容器名称和 Nginx 配置。
